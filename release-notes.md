# Black Screen 1.0.0

A native screensaver that displays only black, with no clock, text, glow, animation, or sound.

## Upgrade guide

First release. Install the APK on Android 6.0 or newer and select Black Screen in your device screensaver settings. No account, permissions, migrations, or configuration is required. Uninstalling removes the app.

## Breaking changes

None. This is the first release.

## Major changes

- Pure-black DreamService and native full-screen preview.
- D-pad accessible settings, Preview, and offline Credits and license.

## Minor changes and fixes

None.

## Verification and limitations

The signed APK builds with Android SDK 36. Native emulator checks verified every RGB pixel equals zero in two separated preview captures, D-pad Preview, Back, Home, and relaunch. Physical Dream verification is recorded separately in the delivery evidence. This screensaver does not power off the television or control its backlight. Banner automation was deferred at the user’s request.
